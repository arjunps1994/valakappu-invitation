# Valakappu invitation

Run `npm ci` and `npm run dev` to preview the invitation locally. Run `npm run build` to generate the static site in `out`.

To enable WhatsApp RSVP, set `NEXT_PUBLIC_RSVP_WHATSAPP` before building. Use the full phone number with its country code, digits only. The RSVP section is hidden when the number is absent or invalid.
